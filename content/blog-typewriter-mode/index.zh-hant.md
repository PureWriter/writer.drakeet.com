# 打字機模式是什麼？兩種意思與關閉方法

寫作軟體裡的「打字機模式」，是模仿打字機書寫感受的一類顯示方式，常見有兩種意思：一種是讓正在寫的那一行一直停在螢幕的固定高度，可以稱為「打字機捲動」；另一種是只讓游標所在的句子、行或段落清楚顯示，其餘文字變淡，可以稱為「聚焦顯示」。各家軟體用這個詞指的東西不一樣，有的指前者，有的指後者，也有兩種都提供的。

## 兩種「打字機模式」

### 打字機捲動：打字的位置不動，文字往上移

在一般的編輯器裡，文字越寫越多，游標一路往下走，到了螢幕底部之後，每多寫一行，畫面才往上捲一點。寫長文時，視線大半時間停在螢幕下緣；在手機上，鍵盤一跳出來，這個位置還會更低。

打字機捲動把正在寫的那一行固定在螢幕的某個高度，通常是中間。每換一行，是整頁文字往上移，而不是游標往下走。這和用打字機打字很像：落字的位置始終不變，換行時是紙張往上捲。

### 聚焦顯示：只看清楚正在寫的那一段

聚焦顯示不改變捲動方式，改變的是文字的明暗：游標所在的那一句、那一行或那一段照常顯示，其餘文字變淺、變淡。寫到下一段時，清楚的範圍也跟著移過去。

它模仿的是打字機的另一個特點：打出去的字很難再修改，只能一直往下寫。把前文淡化，是為了讓人少看前面、多寫後面。

### 兩者比較

| | 打字機捲動 | 聚焦顯示 |
|---|---|---|
| 是什麼 | 正在寫的那一行停在螢幕固定高度，換行時整頁往上移 | 游標所在的句子、行或段落正常顯示，其餘文字變淡 |
| 改變的是 | 文字在螢幕上的位置 | 文字的明暗 |
| 解決什麼問題 | 視線不必一直追著螢幕底部，看的位置比較穩定 | 注意力不被前文分散，減少回頭修改的衝動 |

兩者並不衝突，有些軟體可以同時開啟。看到某個軟體寫著「打字機模式」，先弄清楚它指的是哪一種；如果開啟後的效果和預期不同，您要找的可能是另一種。

## 什麼時候適合用打字機模式

### 適合寫初稿

寫初稿最怕寫幾句就回頭修改。前文清清楚楚擺在眼前，很容易忍不住去調整用字、刪改段落，寫作的節奏也就斷了。聚焦顯示把前文淡化，讓注意力留在正在寫的這一段；打字機捲動讓落字的位置停在看起來舒服的高度，長時間寫作也不必低頭追著螢幕底部。

聚焦顯示還有一個附帶的好處：變淡的文字隔一段距離就不容易看清，旁人從背後瞄一眼螢幕，也不太容易看出您寫了什麼。

### 修改與校對時最好關閉

修改和校對需要通讀全文、前後對照：情節有沒有矛盾，同一個詞是不是用得太多，段落之間接得順不順。這時其餘文字被淡化，反而妨礙閱讀，應該關閉聚焦顯示。打字機捲動對修改的影響小一些，但正在編輯的位置固定在螢幕中間時，下方能顯示的內容會變少，想在一個畫面裡看到更多文字時，也可以關閉。

所以不少人在寫初稿時開啟打字機模式，改稿時關閉，把它當成「寫」與「改」兩種狀態的切換。

## 純純寫作的打字機模式

純純寫作（Pure Writer）是一款寫作用的文字編輯器，有 Android 版、iOS 版與桌面版。它的「打字機模式」屬於上面的第二種：游標所在的段落正常顯示，其他文字被淡化。三個版本的情況不同：

- **Android 版**：在「設定」中開啟或關閉「打字機模式」。在「設定 › 少數派選項」的「打字機模式」中，還可以選擇「『突出顯示目前段落、淡化其他段落』模式」或「『突出顯示目前列、淡化其他列』模式」（需要純純寫作 Pro）。
- **iOS 版**：在「設定」中開啟或關閉「打字機模式」。它只突顯目前段落，僅對純文字文章生效，在 Markdown 文章中不生效。
- **桌面版**：沒有這種淡化效果。「設定」中另有一個選項，讓目前編輯的最後一行自動捲動到螢幕中間，從選項的名稱來看，它比較接近上面的第一種意思。

## 常見問題 {#faq}

### 打字時只有一段文字是清楚的，其他文字都變淡了，是怎麼回事？

這通常是開啟了聚焦顯示一類的打字機模式：軟體只讓游標所在的段落（或句子、行）正常顯示，其餘文字被淡化。文字本身沒有任何改變，關閉這項顯示就會恢復。在純純寫作裡，這就是「打字機模式」，Android 版與 iOS 版都可以在「設定」中關閉「打字機模式」；Android 版也可以設為只突顯游標所在的那一行，看到只有一行是清楚的，也是同一個原因。

### 打字機模式怎麼關閉？

在所用軟體的設定中找到「打字機模式」或名稱相近的開關，關閉即可。純純寫作的做法是：

- **Android 版、iOS 版**：在「設定」中關閉「打字機模式」。
- **桌面版**：沒有淡化效果，不需要關閉；如果不想讓正在編輯的最後一行捲動到螢幕中間，在「設定」中關閉讓它自動捲動到螢幕中間的那個選項。

### 打字機模式和專注模式是一樣的嗎？

不一樣。「專注模式」在各家軟體裡的意思不盡相同，常見的做法是收起工具列、選單等介面元素，讓畫面上只剩正文；打字機模式作用在正文本身，改變的是文字的位置或明暗。

純純寫作 Android 版有一項「狀態列專注模式」，它只簡化系統狀態列，保留電量等必要的圖示，與打字機模式無關。它在「設定 › 狀態列專注模式」，僅在「隱藏狀態列，更加沉浸和專注」關閉時可用。iOS 版沒有這一項；想讓寫作畫面更簡潔，可以在「設定」中開啟「隱藏系統狀態列」。

### Markdown 文章也能使用打字機模式嗎？

要看所用的軟體。純純寫作 iOS 版的打字機模式僅對純文字文章生效，在 Markdown 文章中不生效。

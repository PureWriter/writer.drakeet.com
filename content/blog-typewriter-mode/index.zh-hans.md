# 打字机模式是什么意思？两种含义与怎么关闭

写作软件里的「打字机模式」，指的是模仿打字机书写体验的一类显示方式。这个词常见有两种含义：一种是让正在写的那一行始终停在屏幕的固定高度，可以叫「打字机滚动」；另一种是只让光标所在的句子、行或段落正常显示，其余文字淡化，可以叫「聚焦显示」。不同软件用这个词指的并不一样，有的指前者，有的指后者，也有两者都提供的。

## 两种「打字机模式」

### 打字机滚动：落字的位置不动，文字往上走

在普通的编辑器里，文字越写越多，光标一路往下，到了屏幕底部之后，每写一行，页面才往上滚一点。写长文时，视线大部分时间停在屏幕下沿；手机上弹出软键盘后，这个位置还会更靠下。

打字机滚动把正在写的那一行固定在屏幕的某个高度，多数放在中间。每换一行，是整页文字往上移，而不是光标往下走。这和在打字机上打字很像：落字的位置始终不变，换行时是纸往上卷。

### 聚焦显示：只看清正在写的那一段

聚焦显示不改变滚动，而是改变文字的明暗：光标所在的那一句、那一行或那一段照常显示，其余文字变浅、变淡。写到下一段时，高亮跟着移过去。

它模仿的是打字机的另一面：打出去的字很难再改，写作的人只能往前写。把前文淡化，是为了让人少看前面、多写后面。

### 两者对比

| | 打字机滚动 | 聚焦显示 |
|---|---|---|
| 是什么 | 正在写的那一行停在屏幕固定高度，换行时整页上移 | 光标所在的句子、行或段落正常显示，其余文字淡化 |
| 改变的是 | 文字在屏幕上的位置 | 文字的明暗 |
| 解决什么问题 | 视线不用一直追着屏幕底部，看的位置更稳定 | 注意力不被前文分散，减少回头修改的冲动 |

两者互不冲突，有的软件可以同时打开。看到某个软件说「打字机模式」，先确认它指的是哪一种；如果打开后效果和预想的不一样，可能是在找另一种。

## 打字机模式适合什么时候用

### 适合写初稿

初稿最怕写几句就回头改。前文清楚地摆在眼前，人很容易忍不住去调整措辞、删改段落，写作的节奏因此被打断。聚焦显示把前文淡化，让注意力留在正在写的这一段；打字机滚动让落字的位置停在视线舒服的高度，长时间写作时不用低头追着屏幕底部。

聚焦显示还有一个附带的作用：被淡化的文字隔一段距离就不容易看清，旁人从身后瞥一眼屏幕，也不容易看清您写了什么。

### 修改和校对时最好关掉

修改与校对需要通读全文、前后对照：情节有没有矛盾，同一个词是不是用了太多次，段落之间衔接得是否自然。这时其余文字被淡化，反而妨碍阅读，应当关掉聚焦显示。打字机滚动对修改的影响小一些，但正在编辑的位置固定在屏幕中间时，它下方能显示的内容会变少，需要在一屏里看到更多文字时，也可以关掉。

所以不少人在写初稿时打开打字机模式，改稿时关闭，把它当作「写」与「改」两种状态的切换。

## 纯纯写作里的打字机模式

纯纯写作（Pure Writer）是一款写作用的文本编辑器，有 Android 版、iOS 版与桌面版。它的「打字机模式」属于上面的第二种：光标所在的段落正常显示，其他文字被淡化。三端的情况不同：

- **Android 版**：在「设置」中打开或关闭「打字机模式」。在「设置 › 少数派选项」的「打字机模式」中，还可以选择「『高亮当前段落、淡化其他段落』模式」或「『高亮当前行、淡化其他行』模式」（需要纯纯写作 Pro）。
- **iOS 版**：在「设置」中打开或关闭「打字机模式」。它只高亮当前段落，仅对纯文本文章生效，在 Markdown 文章里不生效。
- **桌面版**：没有这种淡化效果。「设置」中另有一项「让当前编辑的末行自动滚动到屏幕中间」，从名字可以看出，它接近上文的第一种含义。

更多说明见使用手册的[打字机模式是什么？](/zh-hans/manual/#打字机模式是什么)。

## 常见问题 {#faq}

### 写作时只有一段文字高亮、其他文字都变淡了，是怎么回事？

这通常是打开了聚焦显示一类的打字机模式：软件只让光标所在的段落（或句子、行）正常显示，把其余文字淡化。文字本身没有任何变化，关掉这项显示就恢复正常。在纯纯写作里，这就是「打字机模式」，Android 版与 iOS 版都可以在「设置」中关闭「打字机模式」；Android 版还可以设为只高亮光标所在的行，看到只有一行高亮也是同一个原因。

### 打字机模式怎么关？

在所用软件的设置里找到「打字机模式」或名称相近的开关，关掉即可。纯纯写作的做法是：

- **Android 版、iOS 版**：在「设置」中关闭「打字机模式」。
- **桌面版**：没有淡化效果，不需要关闭；如果不想让正在编辑的末行滚动到屏幕中间，在「设置」中关闭「让当前编辑的末行自动滚动到屏幕中间」。

### 打字机模式和专注模式是一回事吗？

不是一回事。「专注模式」在不同软件里含义各不相同，常见的做法是收起工具栏、菜单等界面元素，让屏幕上只剩正文；打字机模式作用在正文本身，改变的是文字的位置或明暗。

纯纯写作 Android 版有一项「状态栏专注模式」，它只简化系统状态栏，保留电量等必要的图标，与打字机模式无关。它在「设置 › 状态栏专注模式」，仅在「隐藏状态栏，更加沉浸和专注」关闭时可用。iOS 版没有这一项；想让写作界面更干净，可以在「设置」中打开「隐藏系统状态栏」。

### Markdown 文章也能用打字机模式吗？

取决于所用的软件。纯纯写作 iOS 版的打字机模式仅对纯文本文章生效，在 Markdown 文章里不生效。

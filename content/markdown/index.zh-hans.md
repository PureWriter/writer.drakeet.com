# Markdown 简明教程 {#markdown-简明教程}

Markdown 是一种用纯文本标记格式的写法：写的时候仍是纯文本，用 `#`、`*` 等符号标出标题、加粗等格式，预览和导出时再显示为排版好的样子。它简单易学，纯纯写作的每篇文章都可以单独选择使用纯文本或 Markdown。

## 切换到 Markdown

- **Android 版**：点按顶栏右侧的 `TXT` 图标，图标变为 `M↓`，表示这篇文章已切换为 Markdown。
- **iOS 版**：点按编辑器右上角的按钮（平时显示当前文章的格式），选择「切换为 Markdown」。
- **桌面版**：点按窗口底部状态栏中显示「纯文本」的按钮，选择「Markdown」；也可以右键点按侧栏中的文章或编辑器的标签，选择「切换为 Markdown」。

用同样的方法可以切换回纯文本。切换为纯文本不会去掉文中的 Markdown 标记。

## 预览排版效果

- **Android 版**：在 Markdown 文章里，点按右下角 ⊕ 旁的 `M↓` 小按钮，可以在编辑与预览之间切换。
- **iOS 版**：编辑时会为标题、强调、代码、引用与链接着色，标记仍然可见。排版后的效果在「预览 & 另存为」中查看：点按顶栏右侧的「⋯」打开功能面板，选择「预览 & 另存为 PDF、长图片、docx、epub…」。
- **桌面版**：目前不渲染 Markdown，正文按原样显示，没有预览。在桌面版写的 Markdown 文章同步到手机后，可以在手机上预览。

## 基本写法

按 Markdown 的规定，分段需要**空一行**，比如：

```markdown
第一段

第二段
```

段落里的单个换行，按规定在预览时不换行，要换行需要在**行尾加两个空格**或一个反斜杠 `\`。纯纯写作默认开启了「单个换行视为换行」，按一次回车，预览时就会换行；关闭这个开关后，段落里只隔一个换行的两行会连成一行显示。

另外还需要了解以下内容：

- 使用**前后两个星号**可以加粗文字，如：`**被加粗的内容**`
- 使用**前后一个星号**可以使文字变为斜体，如：`*被斜体的内容*`；也可以用下划线，但在中文句子中间，下划线写法常常不会生效
- 标记都是半角符号，请不要用全角符号（例如「＊」）代替
- 在 Android 版与 iOS 版的 Markdown 文章里，点按**快捷输入栏**最左侧的 `M↓` 按钮，可以打开 Markdown 面板，其中有标题、列表、引用、链接、表格等常用标记，尝试一番就基本掌握了；桌面版没有 Markdown 面板
- 更多写法见《使用手册》的[纯纯写作 Markdown 使用指南](/zh-hans/manual/#纯纯写作-markdown-使用指南)，「单个换行视为换行」开关的位置见其中的[注意事项](/zh-hans/manual/#注意事项)

# マークダウンの書き方：文章を書く人のための基本と一覧

マークダウン（Markdown）は、いくつかの記号でプレーンテキストに見出しや強調、箇条書きなどの書式を書き込む書き方です。たとえば行頭に `# ` と書けば見出し、アスタリスク 2 つで囲めば太字です。ファイルはプレーンテキストのままでどのテキストエディタでも開け、対応アプリでプレビューや書き出しをしたときに整ったレイアウトで表示されます。以下に、文章に必要な十数種類の書き方の一覧と例、つまずきやすいところをまとめます。

## マークダウンとは

Markdown は 2004 年に John Gruber が考案しました。その後 CommonMark という仕様が細かな規則を定め、GitHub がそこに表、取り消し線、タスクリストなどを加えました（GFM と呼ばれます）。対応の範囲や細かな表示は、アプリによって異なることがあります。

```markdown
## 第三章　雨の夜

彼女は手紙を引き出しに戻し、**振り返らなかった**。
```

プレビューでは 1 行目が章の見出しに、「振り返らなかった」が太字になります。Markdown を知らないエディタで開いても、そのまま読めます。

## 文章を書く人にとっての利点

- **キーボードから手を離さずに済む**：見出しも太字も、記号を打つだけです。
- **見えない書式がない**：書式はすべて目に見える文字です。
- **特定のアプリに縛られない**：ファイルはプレーンテキスト（拡張子はふつう .md）で、アプリやパソコンを替えても開けます。
- **いろいろな形式に変換できる**：対応するアプリで、ウェブページ、PDF、Word 文書、電子書籍などに書き出せます。

Markdown が決めるのは構造（ここは見出し）だけで、見た目は表示するアプリが決めます。そのため、書式の決まった履歴書のようにフォントや余白、改ページを細かく指定したい書類や、写真と文字を複雑に組む紙面には向きません。

## 基本の書き方一覧

| 書式 | 書き方 | 表示 |
|---|---|---|
| 見出し | `# 第一章` | 大見出し。`##` で一段下、6 段階まで |
| 太字 | `**振り返らなかった**` | **振り返らなかった** |
| 斜体 | `*雨が降っていた*` | *雨が降っていた* |
| 取り消し線（拡張） | `~~この一文を削る~~` | ~~この一文を削る~~ |
| 箇条書き | `- 登場人物のメモ` | 先頭に点がつく項目 |
| 番号付きリスト | `1. 発端` | 先頭に番号がつく項目 |
| 引用 | `> 引用した一節` | 本文と区別された引用 |
| 区切り線 | 1 行に `***` または `---` だけを書く | 横線。場面転換に使える |
| リンク | `[純純執筆](https://writer.drakeet.com)` | クリックできる文字「純純執筆」 |
| 画像 | `![表紙のラフ](cover.jpg)` | 画像。角かっこの中は画像の説明 |
| インラインコード | `` `Ctrl+S` `` | `Ctrl+S`（等幅でそのまま表示） |
| コードブロック | 前後の行に `` ``` `` | 間の内容をそのまま表示 |
| 表（拡張） | 下の例を参照 | 表 |
| タスクリスト（拡張） | `- [ ] 第三章を書き上げる` | チェックのない四角。`[x]` でチェック済み |

「拡張」の 3 つは GFM で加わったもので、最初の Markdown にはありません。記号はすべて半角で、全角の「＃」「＊」は働きません。太字や斜体はアンダースコア（`__太字__`、`_斜体_`）でも書けますが、日本語の文の途中では効かないことが多いので、アスタリスクが確実です。

表は縦線 `|` で列を区切り、2 行目のハイフンで見出し行と中身を分けます。揃え方はコロンで決まり、`:---` は左、`:---:` は中央、`---:` は右揃えです。縦線を上下で揃える必要はなく、セルの中の縦線は `\|` と書きます。

```markdown
| 人物 | 立場 | 初登場 |
| :--- | :--- | ---: |
| 森野 | 新聞記者 | 第 1 章 |
| 早瀬 | 中学校教師 | 第 3 章 |
```

## 書き方の例

よく使う書き方をまとめて使った短い原稿です。

```markdown
# 第一章　手紙

　雨は夜になっても止まなかった。森野は窓を閉め、机の上の封筒に目を落とした。

> 明日の朝、駅で待っています。

　差出人の名前はない。手がかりは三つだけだった。

- 消印は三日前
- 宛名は**旧姓**で書かれている
- 便箋に海の匂いが残っている

***

　翌朝、駅はひどく混んでいた。
```

プレビューでは、`>` の行が引用、`-` の 3 行が箇条書き、`***` が場面転換の横線になります。

## つまずきやすいところ

### 改行と段落

```markdown
ひとつ目の段落の最後の文。
ふたつ目の段落の最初の文。
```

CommonMark の規則では、この 2 行は同じ段落で、表示すると 1 行につながります。段落を分けるには空行を 1 行入れます。段落の中で改行したいとき（詩の行分けなど）は、行末に半角スペースを 2 つ置くか、バックスラッシュ `\` を書きます。1 回の改行をそのまま改行として表示するアプリもあります。

### 段落の頭の字下げ

一字下げには全角スペースを使います。行頭に半角スペースを 4 つ以上入れた段落は、コードブロックとして扱われてしまいます。

### 箇条書きの前後には空行

箇条書きのすぐ下に空行を入れずに文を続けると、その文は最後の項目に取り込まれます。次の例では 3 行目が「切符」の一部になります。

```markdown
- 傘
- 切符
駅に着いてから、財布を忘れたことに気づいた。
```

前にも空行を入れるのが確実です。CommonMark では、1 以外の数字で始まる番号付きリストは文のすぐ下にあるとリストになりません。引用も終えるときは空行を入れます。

入れ子にするには、上の項目の文字が始まる位置まで字下げします。`- ` の下なら半角スペース 2 つ、`1. ` の下なら 3 つです。`1. ` の下で 2 つだけだと、別のリストになります。

```markdown
1. 第一章
   - 雨の夜
   - 手紙
2. 第二章
```

### 記号をそのまま書くにはバックスラッシュ

記号の前にバックスラッシュを付けると、`\*` はアスタリスク、`\#` はシャープとしてそのまま表示されます。働くのは半角の記号だけです。日本語の環境ではバックスラッシュが「¥」と表示・入力されることがありますが、Markdown で使えるのは半角のバックスラッシュです。

範囲を表す「〜」は全角なら問題ありません。半角の `~` は、GFM の規則では 1 つずつの組でも取り消し線になり、同じ段落に `3~5 日` と `7~9 日` を書くと、アプリによっては間の文字に線が引かれます。`\~` と書けば避けられます。

### かぎかっこに接したアスタリスクが効かないことがある

`彼は**「待って」**と言った。` は、アスタリスクがそのまま表示されがちです。CommonMark では、アスタリスクの片側が文字、反対側が括弧や句読点だと書式にならないことがあるためです。`彼は「**待って**」と言った。` と、かっこを外に出せば太字になります。

### 見出しのシャープの後ろには半角スペース

`#第一章` は普通の文字のままで、`# 第一章` が見出しです。また、場面転換の `---` はすぐ上に空行を入れないと、上の行が二段目の見出しになります。`***` を使えばこの問題は起きません。

## 純純執筆で Markdown を使う

純純執筆（Pure Writer）は文章を書くためのテキストエディタで、本文はプレーンテキストで保存され、リッチテキストには対応していません。見出しや太字が必要なときは、文章ごとに Markdown へ切り替えます。

- **Android 版**：トップバー右側の `TXT` アイコンをタップすると `M↓` に変わり、Markdown になります。右下の ⊕ の横にある小さな `M↓` ボタンで、編集とプレビューを切り替えます。
- **iOS 版**：エディタ右上の、ふだんは文章の形式を表示しているボタンから「Markdown に切り替え」を選びます。編集中は見出しや強調などに色が付き、記号は見えたままです。仕上がりは「…」のパネルの「プレビュー / PDF・縦長画像・DOCX・EPUB として保存…」で確認します。
- **パソコン版**：ウィンドウ下部のステータスバーにある「プレーンテキスト」をクリックし、「Markdown」を選びます。今のところプレビューはなく、スマートフォンに同期すればそちらでプレビューできます。

3 つとも、記号を隠して仕上がりの見た目で編集する機能はありません。Android 版と iOS 版では、ショートカットバー左端の `M↓` ボタンで Markdown パネルを開き、見出しや表などを挿入できます（パソコン版にはありません）。

一般的な説明と違う点もあります。

- CommonMark を基本に、表、タスクリスト、取り消し線、LaTeX の数式、一部の HTML タグに対応。`==ハイライト==`、脚注、`<center>` タグには非対応で、中央揃えは `<p align="center">…</p>` と書きます。
- 1 回の改行をそのまま改行として表示する設定が、最初からオンです。iOS 版は「設定 › Markdown オプション」の「単一の改行を改行として扱う」、Android 版は「こだわりの設定」の「GFM line breaks / Soft break adds new line」です。
- 取り消し線になるのはチルダ 2 つだけで、半角のチルダ 1 つは範囲に使えます。
- テキストファイルで書き出すと .md になります。.txt にしたいときは先にプレーンテキストに切り替えます（記号は消えません）。Android 版と iOS 版はプレビューの画面から PDF、DOCX、EPUB などでも保存できます（Android 版は純純執筆 Pro が必要）。

書き方の詳細は、マニュアルの [Pure Writer Markdown User Guide](/en/manual/#pure-writer-markdown-user-guide)（英語）にあります。

## よくある質問 {#faq}

### マークダウンで改行するには？

段落を分けるときは空行を 1 行入れます。段落の中での改行は、CommonMark の規則では行末に半角スペースを 2 つ置くか、バックスラッシュ `\` を書きます。改行キーを 1 回押すだけでは 2 行がつながります。ただし 1 回の改行をそのまま表示するアプリもあり、純純執筆も最初からそう表示します。

### マークダウンで表を書くには？

1 行目に見出しを書いて縦線 `|` で列を区切り、2 行目に列ごとのハイフン（例：`| --- | --- |`）を書き、3 行目から 1 行に 1 件ずつ書きます。ハイフンの横のコロンで揃え方が決まり、`:---` は左、`:---:` は中央、`---:` は右揃えです。表の前後には空行を入れ、セルの中の縦線は `\|` と書きます。

### スマホでもマークダウンは書ける？

書けます。Markdown はプレーンテキストなので、文字を入力できるアプリなら書けます（プレビューできるかはアプリしだいです）。純純執筆の Android 版と iOS 版では、Markdown に切り替え、Markdown パネルで記号を挿入し、仕上がりをプレビューできます。

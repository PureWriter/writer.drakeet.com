# Pure Writer desktop Privacy Policy {#pure-writer-desktop-privacy-policy}

## Software Information {#software-information}

Pure Writer desktop is a writing app that pursues non-loss and reassurance, featuring extremely fast startup speeds and a smooth writing experience.

## Basic Statement {#basic-statement}

Pure Writer desktop does not collect your private information. It only queries the following contents unrelated to your personal information:

- Error logs: Relevant code stack information automatically generated by the system when the app crashes. We automatically report it to our server via the internet.

- Usage statistics: Some events are also reported to our server, such as switching themes, the app not responding, and daily statistics on cloud sync and backup (for example, the amount of data uploaded and downloaded) along with the errors they run into, which may include backup file names. They help us find and fix problems and don't include the content of your documents.

- Device information: Requests to our server, such as checking for updates, reading feature settings (for example, whether to report errors), reporting errors and usage statistics, and connecting a cloud drive, include a device identifier randomly generated by Pure Writer desktop, your computer's name as set in your system, the operating system and its version, the processor architecture, the app version and language, when you first used the app, whether your computer is set to China's time zone, and the type of cloud drive you've connected (not your account). The device identifier is not derived from your hardware.

## Copyright of Works {#copyright-of-works}

Pure Writer desktop is merely a creative tool. The works you create in it **completely belong to you personally**, and you also fully own the copyright, authorship, and other rights of the works.

## Permissions Requested {#permissions-requested}

Pure Writer desktop will automatically create a folder named 'Pure Writer' in your system's Documents folder, where it will store your database and some backup files. It won't read any of your other files except for this folder.

## Article Data and Backup {#article-data-and-backup}

By default, Pure Writer desktop does not automatically perform cloud backups. Pure Writer desktop only supports third-party cloud storage as your cloud backup space. Pure Writer desktop does not provide official cloud backup disk services. Therefore, you can set your OneDrive or Dropbox, etc., in Pure Writer desktop as the cloud backup service space. Pure Writer desktop will strictly encrypt and transmit your article backups to your cloud storage via HTTPS. Due to the security of HTTPS itself, no one can intercept and view the content during transmission, and your content can only be seen by you on your cloud storage, or pulled and viewed in Pure Writer desktop. **Apart from you, including the developers, no one can see your backups and article contents**.

## Cloud Drive Accounts {#cloud-drive-accounts}

Pure Writer desktop doesn't need a Pure Writer account. For cloud backup and sync, you connect your own OneDrive, Dropbox or Aliyun Drive account. You sign in on the cloud drive's own website in your browser, so Pure Writer desktop never sees your password. After you authorize it, Pure Writer desktop saves the access token and your account name (such as an email address or a phone number) in its settings on your computer, and uses the token to connect to your cloud drive directly. Disconnecting the cloud drive in Pure Writer desktop removes them from your computer.

For OneDrive and Dropbox, the one-time authorization code that the cloud drive returns after you sign in is passed to Pure Writer desktop through our server, which keeps it only until Pure Writer desktop picks it up. Pure Writer desktop then gets and renews the access token directly from Microsoft or Dropbox. Aliyun Drive works differently, as described below.

## Aliyun Drive {#aliyun-drive}

Aliyun Drive's authorization goes through our server. After you sign in and authorize Pure Writer desktop on Aliyun Drive's website, Aliyun Drive sends the authorization code to our server, which exchanges it for an access token and a refresh token, holds them until Pure Writer desktop picks them up, and then deletes them. When the access token expires, Pure Writer desktop sends the refresh token to our server, which gets a new access token from Aliyun Drive and returns it. To cope with Aliyun Drive being temporarily unavailable, our server keeps the most recent result in memory (not in its database) and may return it again within a day. Your backups and documents are uploaded to and downloaded from Aliyun Drive directly and never pass through our server.

With Aliyun Drive, cloud sync keeps its sync index on our server instead of in your Aliyun Drive. The sync index records backup file names, device names, document IDs and sync times, but not the content of your documents, and is identified by your Aliyun Drive user ID. Requests about the sync index, including the check Pure Writer desktop makes before clearing old backups from your Aliyun Drive, carry your Aliyun Drive user ID and backup file names, but not your access token.

## Checking for Updates {#checking-for-updates}

Pure Writer desktop checks our server for updates when it starts and from time to time while it's running. Besides the device information described above, the request includes the installed version and whether GitHub can be reached from your computer: when it starts, Pure Writer desktop tries connecting to a few GitHub addresses to find out, and those requests carry no information about you. Our server uses this to choose a suitable update and download source, and keeps a record for each device identifier with your computer's name, the operating system and its version, the processor architecture, the app version, when the device first and last checked for updates, and how many times it has checked. When a new version is available, Pure Writer desktop downloads it from our servers and starts using it the next time you open it.

## Fanhuaji Conversion {#fanhuaji-conversion}

When the app language is Simplified Chinese, the Formatting options menu includes "台灣化（繁化姬）". Choosing it sends the full text in the current editor over HTTPS to Fanhuaji (<https://zhconvert.org>), a third-party service, to convert it into Traditional Chinese with Taiwanese usage. Pure Writer desktop explains this and asks for your consent before the first use. The request contains no account or device information. Nothing is sent unless you choose this option; the other Chinese conversions run on your computer and don't need a connection.

## Updates to This Policy {#updates-to-this-policy}

We may modify and update this privacy policy from time to time. You can visit this page at any time to check the latest version of the privacy policy.

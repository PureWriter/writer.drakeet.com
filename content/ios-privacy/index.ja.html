純純執筆 iOS 版 プライバシーポリシー

最終更新日：2026年11月5日　施行日：2026年11月5日

純純執筆 iOS 版（以下「本アプリ」。iPhone および iPad 向け）は、Drakeet Co., Ltd.（以下「当社」）が開発・運営しています。本ポリシーでは、本アプリが取り扱う情報の種類と目的、共有先、保存期間、およびお客様による管理の方法について説明します。

1. 文章はお客様のデバイスに保存されます

本アプリで作成した文章、履歴、設定は、お客様のデバイスに保存されます。当社には文章を保存するサーバーがなく、当社が文章を読むこともできません。文章がデバイスの外に送信されるのは、第 3 項に記載した機能をお客様がオンにした場合、または利用に同意した場合に限られ、お客様が選んだサービスへ直接送信されます。

本アプリには広告がなく、アプリやウェブサイトをまたいだトラッキングを行わず、広告識別子を収集せず、お客様の個人情報を販売することもありません。

2. 当社が収集する情報

2.1 エラーレポートと利用統計

問題の発見と製品の改善のため、本アプリは Google が提供する Firebase を通じて次の情報を収集します。

  • エラーレポート：クラッシュやエラーが発生したときのアプリの状態、デバイスの機種、OS のバージョン、アプリのバージョン。
  • 利用統計：機能の利用状況、設定の好み（テーマ、書き出し形式、利用中のクラウドドライブの種類など）、試用と購入の状況（購入した商品と金額など）、および Firebase が IP アドレスから推定するおおよその地域。

これらの情報は、Firebase がこのインストールごとにランダムに生成する識別子に関連付けられます。純純執筆アカウントには関連付けられず、文章、タイトル、検索内容、アカウント情報は含まれません。

いずれも初期設定でオンになっています。「設定 › 詳細オプション」で「エラーレポートを送信」と「利用統計を送信」をそれぞれいつでもオフにできます。オフにすると、本アプリは該当する情報を送信しなくなります（エラーレポートの変更は次回の起動後に完全に反映されます）。利用統計をオフにすると、デバイス上の統計データも消去されます。すでに送信された情報は取り消せません。

2.2 純純執筆アカウント（任意）

本アプリではアカウントを新規登録できず、ログインしなくても本アプリを利用できます。純純執筆アカウントは会員の状態を確認するためだけに使われ、文章は保存されません。すでに純純執筆アカウントをお持ちの場合は、ログインして、そのアカウントの会員特典を引き続き利用できます。

ログイン、確認コードの取得、パスワードの再設定、ログイン状態の維持の際に、本アプリは当社のサーバーに次の情報を送信します：メールアドレス、パスワードまたは確認コード、本アプリがデバイス上でランダムに生成するデバイス識別子、デバイスの機種、OS のバージョン、アプリのバージョン、表示言語、試用の状況。

当社のサーバーは、本人確認、会員特典の確認、ログイン中のデバイスの管理のため、メールアドレス、ハッシュ化したパスワード（元のパスワードは保存しません）、ログイン中のデバイスとその機種を保存します。本アプリ自体はパスワードを保存しません。

2.3 お知らせと機能スイッチの確認

重要なお知らせやアップデートをお伝えするため、本アプリは定期的に（最大で 12 時間に 1 回）当社のサーバーにお知らせを確認します。リクエストに含まれるのは、アプリのバージョンとインストール元（App Store または TestFlight）、OS のバージョン、表示言語、デバイスの機種、システムの地域が中国本土かどうか、利用中のクラウドドライブの種類のみで、アカウントやデバイス識別子など、お客様を特定できる情報は含まれません。

また、必要に応じてクラウド同期の方式を調整できるよう、本アプリは当社のサーバーから機能スイッチをときどき読み込みます。このリクエストには、アカウントやデバイス識別子など、お客様を特定できる情報は含まれません。

2.4 AliyunDrive を利用する場合

AliyunDrive を連携すると、認可を完了するため、認可情報が当社のサーバーを経由して受け渡されます。当社のサーバーはこれを保存しません。

連携後は、複数のデバイス間の同期を調整し、ほかのデバイスがまだ使っているバックアップを整理の対象にしないよう、本アプリは AliyunDrive のユーザー ID と関連するバックアップのファイル名を当社のサーバーに送信します。クラウド同期をオンにすると、当社のサーバーは AliyunDrive のユーザー ID と同期記録（バックアップのファイル名とそれを含むフォルダ、デバイスの機種、同期日時など。フォルダ名はランダムに生成された識別子です）を保存します。文章の内容や AliyunDrive のログイン情報は含まれません。

2.5 サーバーのアクセスログ

一般的なオンラインサービスと同様に、当社のサーバーは上記のリクエストを処理する際、IP アドレスやアクセス日時などのアクセスログを記録します。これらはサービスの運用と安全の確保のためにのみ使用します。

3. お客様の選択により第三者のサービスへ直接送信される内容

3.1 iCloud にバックアップ

iCloud が利用できるときは、機種変更や再インストールのあとに復元できるよう、本アプリは初期設定で自動バックアップのコピーをお客様ご自身の iCloud に保存します。バックアップは Apple の iCloud サービスを通じてお客様の Apple アカウントに直接保存され、当社のサーバーを経由せず、当社が読むこともできません。「設定 › バックアップとクラウド同期 › iCloud にバックアップ」で、この機能をオフにしたり、iCloud 内のバックアップをすべて削除したりできます。

Apple アカウントの国または地域が中国本土の場合、iCloud は Guizhou-Cloud Big Data Industry Co., Ltd.（GCBD）が運営しています。

3.2 クラウドドライブへのバックアップとクラウド同期

「設定 › バックアップとクラウド同期 › クラウドドライブ」でお客様ご自身の Dropbox、OneDrive、AliyunDrive のアカウントを連携した場合にのみ、本アプリは自動バックアップと、お客様がアップロードを選んだ手動バックアップをそのクラウドドライブにアップロードします。クラウド同期をオンにすると、ほかのデバイスがアップロードしたバックアップのダウンロードと統合も行います。

バックアップファイルは HTTPS でお客様のデバイスとクラウドドライブの間で直接やり取りされ、当社のサーバーを経由しません。バックアップファイル自体には追加の暗号化を行っておらず、クラウドドライブに保存された内容には各サービス提供者のプライバシーポリシーが適用されます。クラウドドライブのログイン情報はお客様のデバイスにのみ保存され、連携を解除するとアップロードは停止します。

3.3 オンラインでの中国語変換

表示言語が中国語のときに繁化姬による簡体字・繁体字の変換を選ぶと、本アプリは初回の利用前にお客様の同意を得たうえで、現在の文章の本文を第三者サービス「繁化姬」に送信して変換します。リクエストにはアカウントやデバイスの識別子は含まれません。この機能を使わない限り、何も送信されません。

3.4 Markdown 内のウェブ画像

Markdown の本文でウェブ上の画像を参照している場合、プレビューや書き出しの際に、本アプリはそのアドレスから画像を直接ダウンロードします。その際、画像のあるウェブサイトは、お客様の IP アドレスなどのネットワークリクエストの情報を取得できます。

3.5 購入

本アプリでの購入とサブスクリプションは、Apple が App Store を通じて処理します。当社がお客様の支払い情報を受け取ることはありません。

4. システムの権限

本アプリが「写真の追加」の許可を求めるのは、画像を写真ライブラリに保存するときのみで、既存の写真は読み取りません。画像を選ぶときはシステムのピッカーを使うため、お客様が選んだ画像だけが本アプリに渡されます。本アプリは位置情報、連絡先、カメラ、マイクへのアクセスを求めません。

5. 第三者のサービス

本アプリに関わる第三者のサービスは次のとおりです。

  • Google（Firebase）：エラーレポートと利用統計。プライバシーポリシー
  • Apple：iCloud バックアップと App Store での購入。プライバシーポリシー
  • Dropbox：お客様が連携したクラウドドライブ。プライバシーポリシー
  • Microsoft（OneDrive）：お客様が連携したクラウドドライブ。プライバシーに関する声明
  • AliyunDrive：お客様が連携したクラウドドライブ。同社のプライバシーポリシーが適用されます。
  • 繁化姬：オンラインでの中国語変換。

当社は、本ポリシーに記載した目的に必要な範囲でのみ上記のサービス提供者と情報を共有し、ユーザーデータを共有する第三者が本ポリシーと同等以上の保護を提供することを確認しています。お客様がご自身で連携したサービス（クラウドドライブのアカウントなど）には、各サービスのプライバシーポリシーも適用されます。

6. 保存期間と削除

  • デバイス上のデータ：本アプリを削除すると一緒に削除されます。デバイスのバックアップ（iCloud バックアップなど）に含まれるコピーは、システムとお客様の設定によって管理されます。
  • エラーレポートと利用統計：Firebase の保存期間に従って自動的に削除されます。
  • アカウント情報：アカウントを削除するまで保存します。
  • iCloud とクラウドドライブ内のバックアップ：お客様ご自身のアカウントに保存され、お客様が管理します。iCloud 内のバックアップは本アプリ内からも削除できます。

純純執筆アカウントにログイン後、Pro ページ下部の「アカウントを削除」をタップし、警告を読んで確認すると、アカウントを完全に削除できます。アカウント情報と会員資格が削除され、すべてのデバイスでそのアカウントが使えなくなります。デバイス上の文章や設定、iCloud やクラウドドライブ内のバックアップ、クラウド同期のデータ、Apple で購入した Pro には影響しません。クラウドのバックアップと同期データは、お客様ご自身の iCloud またはクラウドドライブのアカウントで管理され、純純執筆の会員アカウントとは別のものです。「設定 › バックアップとクラウド同期」でバックアップ、同期、クラウドドライブの連携を管理できます。クラウドドライブ内のデータは、そのサービスで削除してください。連携を解除しても保存済みのデータは削除されません。アカウントを削除しても Apple のサブスクリプションは解約されません。自動更新を停止するには、Apple のサブスクリプション管理で別途解約してください。

7. お客様の選択と権利

  • エラーレポートや利用統計はいつでもオフにできます。
  • いつでもログアウトできます。また、Pro ページで純純執筆アカウントを削除できます。
  • 「iCloud にバックアップ」のオフ、クラウドドライブの連携解除、クラウド同期のオフができます。

8. 本ポリシーの変更

当社は本ポリシーを適宜更新することがあります。更新後のポリシーは、更新日とともに本ページに掲載します。重要な変更がある場合は、適切な方法でお知らせします。

# 写小说用什么软件？手机、苹果手机和电脑怎么选

写小说用什么软件，没有唯一的答案，取决于三件事：在哪里写（手机、平板、电脑，还是几样都用）；写多长；稿子怎么保存、以什么格式交稿。无论选哪一款，先看这四条：稿子不会丢；在您用的每台设备上都能接着写；长篇能分章管理；能导出交稿需要的格式。

## 写小说常用的四类软件

| 类别 | 长处 | 短处 |
|---|---|---|
| 通用的文档软件（例如 Word） | 排版能力强；Word 文档（.docx）是交稿常用的格式 | 整部小说放在一个文件里，越大越慢；在手机上编辑长文档不一定顺手 |
| 笔记软件 | 随手记灵感方便，多数支持多设备同步 | 多为短笔记设计，几百章的排序、合并导出不一定方便 |
| 专门的写作软件 | 围绕码字设计，常有分章管理、字数统计、快捷输入 | 各家支持的平台不同，有的只有手机版或只有电脑版 |
| 连载平台自带的作家工具 | 写完可以直接提交到平台 | 稿子与平台账号绑定；投多家或换平台时，要确认能否完整导出 |

## 选码字软件时看什么

| 标准 | 为什么要紧 | 怎么自己验证 |
|---|---|---|
| 稿子会不会丢 | 长篇动辄几十万字，丢一章就是几天的工作 | 写一段后把软件从后台关掉再打开；删掉一段，看能否从历史版本找回；看备份能否自动存到设备之外 |
| 能否在手机和电脑之间接着写 | 灵感常在路上，修改多在电脑前 | 手机上写一句，到电脑上看它何时出现；两边改同一章，看保留哪一版 |
| 长篇怎么管理 | 章节一多，找一章、调顺序都费时间 | 建二三十章，试着拖动调整顺序，按记得的一句台词查找 |
| 码字顺手不顺手 | 每天都要用，小的不便会累积 | 粘贴几万字进去打字，看有无延迟；看能否一键输入「」和人名、一次整理缩进与空行 |
| 能导出什么格式 | 投稿、给编辑看，常要 Word 文档或 TXT | 导出 DOCX 用 Word 打开，看分段与章节标题是否完整；试试能否把多章合成一个文件 |
| 稿子存在哪里 | 未发表的稿子不想被别人看到 | 读隐私政策里文字存在哪里、会不会上传到服务商的服务器 |
| 离线能不能写 | 地铁、飞机上常常没有网络 | 打开飞行模式写一段，联网后看能否同步 |
| 数据能否完整带走 | 一部长篇可能写上几年，软件可能停更或被换掉 | 确认能否导出全部稿子，格式是不是 TXT、DOCX 这类通用格式 |

防丢的做法见《[写小说怎么存稿才不会丢？](/zh-hans/blog/never-lose-your-draft/)》，判断软件是否安全见《[码字软件会被盗文吗？](/zh-hans/blog/writing-app-privacy/)》。

## 不同情况怎么选

### 主要用手机写

优先看输入顺手与防丢：长章节里打字不卡，常用符号与人名能一键输入，自动保存。手机容易丢失或损坏，备份一定要存在手机之外。

### 用苹果手机或 iPad 写

先看 App 支持的系统版本与设备是否对得上；iPad 配外接键盘时，留意有没有键盘快捷键。如果电脑是 Windows，先确认这款软件有 Windows 版，或者稿子能通过网盘在两边打开。

### 主要用电脑写

电脑打字快、屏幕大，适合长时间写作与修改。用文档软件也可以，但建议一章一个文件、按编号命名，并把文件夹放进网盘或定期备份，交稿时再合并。

### 手机和电脑都用

关键在同步：两边登录同一个账号或网盘；换设备之前，等这一台同步完成；不要在两台设备上同时改同一章。见《[手机和电脑同步写作怎么设置？](/zh-hans/blog/sync-writing-between-phone-and-computer/)》。

### 新人刚开始写

不必在挑软件上花太多时间。选一款可以免费使用或试用的，先确认稿子不会丢、写好的能导出来。写满十几章、需要分卷时，再对照上面的标准决定是否更换。

## 纯纯写作适合谁、不适合谁

纯纯写作是一款写作用的文本编辑器，有 Android 版、iOS 版（iPhone 与 iPad）与桌面版（Windows 与 macOS）。

比较适合：

- **担心丢稿的人**：自动保存，另有撤销与重做、历史记录、废纸篓、不能关闭的本机自动备份，以及备份到您自己网盘的云备份，见《[保护机制](/zh-hans/protections/)》。
- **手机和电脑都用的人**：三端连接同一家网盘（阿里云盘、OneDrive 或 Dropbox）的同一个账号并开启云同步，就能接续写作。同步不是逐字实时的，同一篇在两台设备上都改过时，通常保留较晚的那次修改。
- **写长篇的人**：用书、卷、文章三层组织，单篇不限字数，见《[长篇小说怎么分卷分章？](/zh-hans/blog/organize-long-novel-chapters/)》。
- **在手机上码字的人**：快捷输入栏可以放人物名字、成对的引号；「一键排版」一次整理空行、段首缩进与中英文间距。
- **需要导出交稿的人**：Android 版与 iOS 版可以把单篇保存为 TXT、DOCX、EPUB、PDF 等，或用「合并成书导出」把整本书导出为 TXT、DOCX 或 EPUB。

不适合，或需要先知道的：

- 它是文本编辑器，没有社区、信息流或发表平台，写完要自己发到平台或交给编辑。
- 正文是纯文本，不能像文字处理软件那样直接设粗体或在正文中嵌入图片，需要格式时用 Markdown。
- 桌面版目前免费使用，但还不能导出文章；Android 版的核心功能免费，导出等部分功能需要纯纯写作 Pro；iOS 版需要 iOS 26 或 iPadOS 26 及以上版本，免费试用 7 天后，需要订阅或购买永久会员才能继续编辑。

详见《[纯纯写作使用手册](/zh-hans/manual/)》。

## 常见问题 {#faq}

### 写小说用什么软件比较好？

没有适合所有人的一款。先想清楚在哪里写、写多长、怎么交稿，再看四条：稿子不会丢；在用的每台设备上都能接着写；长篇能分章管理；能导出 DOCX、TXT 等交稿需要的格式。最可靠的办法是装上试写几章，把导出、备份与恢复各试一次。

### 手机写小说用什么软件？

专门的写作软件或笔记软件都可以，重点看：几万字的章节里打字是否流畅，能否一键输入常用符号与人名，是否自动保存，备份能否自动存到手机之外。只存在手机里的稿子，会随手机丢失或损坏一起丢失。

### 用苹果手机写小说用什么软件？

先确认 App 支持您的 iOS 版本；如果还用 Windows 电脑，要确认稿子能在 iPhone 与 Windows 之间同步。纯纯写作 iOS 版适用于 iPhone 与 iPad，需要 iOS 26 或 iPadOS 26 及以上版本，可以通过同一个网盘账号与 Android 版、桌面版同步。

### 写小说用 Word 可以吗？

可以，主要在电脑上写、交稿要求 Word 文档时尤其方便。建议一章存一个文件并按编号命名，不要把整部小说放在一个文件里，并把文件夹放进网盘或定期备份到别处。如果还要在手机上写，先试试在手机上编辑长文档是否顺手。

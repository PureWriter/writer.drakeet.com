# 集中して書ける執筆アプリの選び方

集中して書ける執筆アプリとは、書いているあいだ本文以外のものが邪魔をしないアプリのことです。画面には文字のほかにほとんど何もなく、割り込むものもなく、保存や同期、書式を気にせずに済みます。選ぶときは、画面を本文だけにできるか、自動で保存して以前の版も残るか、オフラインで書けるか、タイムラインや広告がないか、すぐに起動するか、ふだん書く端末でどう動くかを確かめるとよいでしょう。

## 気が散る原因

書く手を止めるのは、たいてい小さな中断の積み重ねです。

- **画面の情報**：ツールバー、メニュー、通知アイコンの並ぶステータスバー
- **アプリの中の読み物**：タイムライン、コミュニティ、おすすめ
- **書式の判断**：書き終える前に見た目を整えたくなる
- **保存の心配**：保存されたかわからず、気になる
- **待ち時間**：起動や入力の遅れ
- **アプリの切り替え**：調べものの先で、ほかのものが目に入る

## 執筆アプリで確かめたいこと

### 画面を本文だけにできるか

全画面表示や、入力中にツールバーが隠れる機能があるか。スマートフォンならステータスバーも隠せるか。**試し方**：一段落書いて、本文のほかに何が画面に残るかを数えます。

### タイプライターモード

書いている行を一定の高さに保つ表示と、カーソルのある文や段落以外を淡くする表示があります。読み返して手を入れてしまう方は試す価値があります（違いは「[タイプライターモードとは？](/ja/blog/typewriter-mode/)」）。「フォーカスモード」はアプリによって意味が違うので、名前ではなく何が変わるかで見分けてください。

### 書式ボタンより、プレーンテキストか Markdown

`#` や `*` で見出しや強調を示す Markdown なら、ボタンに手を伸ばさずに書き続けられます。

### 保存を気にせず書けるか

**試し方**：一文書いたらすぐにアプリを閉じ、開き直して文章が残っているかを見ます。以前の版に戻せる履歴の機能があるかも確かめます。

### オフラインで書けるか

文章は端末に保存され、同期は追加の機能であるのが理想です。**試し方**：機内モードで数行書き、アプリを開き直します。

### タイムラインや広告がないか

交流の機能や広告があると、開くたびに注意を奪われます。

### すぐに起動し、続きから書けるか

**試し方**：アプリを起動し直して入力できるまでの時間を見て、前回の文章が前回の位置で開くかを確かめます。

### ショートカットバー（スマホ）

かぎかっこやダッシュ、三点リーダーは、スマートフォンでは入力に手間がかかることがあります。よく使う記号や人物名をキーボードの上に並べられると便利です。

### ダークモードと文字の調整

ダークモードがあるか、文字サイズ、行間、余白を調整できるかを見ます。

### 横向きと外付けキーボード

タブレットを横向きにして、行が端から端まで伸びないかを確かめます。外付けキーボードでショートカットが効くかも見ておきましょう。

## 小説を書くなら

- **縦書き**：縦書きで書きたい方は、選ぶアプリが対応しているかを事前に確認してください。
- **文字数の数え方**：空白や記号を数えるかはアプリによって違います（「[文字数の数え方](/ja/blog/word-count-vs-character-count/)」）。
- **長編**：章ごとに分けられるか、長い原稿でも重くならないか。
- **複数の端末**：スマートフォンとパソコンで同期できるか（[同期の方法と注意点](/ja/blog/sync-writing-between-phone-and-computer/)）。

## スマホ・iPad・パソコンの違い

| 端末 | 特に大切なこと |
|---|---|
| スマートフォン | キーボードが画面の多くを占めるので、バーを隠す機能やショートカットバーの効果が大きい。起動の速さも重要 |
| iPad・タブレット | 横向きでの行の長さ、外付けキーボード、画面分割 |
| パソコン | 広いウインドウでも本文が読みやすい幅に収まるか。システムの通知設定も大切 |

## 純純執筆でできること

純純執筆（Pure Writer）は、Android、iPhone・iPad、パソコン（Windows・macOS）で使えるプレーンテキストエディタです。コミュニティやタイムライン、投稿の場はなく、Android 版の無料の機能に広告はありません。文章は端末に保存され、バックアップと同期の保存先はご自身の iCloud またはクラウドドライブだけです。

Android 版と iOS 版では、次のことができます。

- **タイプライターモード**：カーソルのある段落のほかを淡くします。Android 版は「設定」の「タイプライター」、iOS 版は「設定」の「タイプライターモード」でオンにします。
- **バーを隠す**：スクロール時にトップバーを自動で隠し、iOS 版の没入モードでは入力を始めると収めます。ステータスバーは Android 版の「設定」の「ステータスバーを非表示」、iOS 版の「設定」の「ステータスバーを非表示にする」で隠せ、Android 版には「ステータスバーフォーカスモード」もあります。
- **続きから書く**：前回編集していた文章を開き、スクロール位置も復元します。
- **読みやすさ**：横長の画面でも本文はほどよい行の長さを保ちます。文字サイズ、行間、余白を調整でき、ライトとダークの外観があります。
- **そのほか**：ショートカットバー、自動保存と履歴、文章ごとの Markdown 切り替え。

外付けキーボードでは、Android 版は Alt または Ctrl と数字キーでショートカットを入力でき、iOS 版も iPad でショートカットに対応しています。パソコン版は本文の幅に上限があり、履歴を備えています。

## 純純執筆が向かないこと

- パソコン版には淡色表示がなく、Markdown はプレビューできず、現在は文章を書き出せません。
- iOS 版は iOS 26 または iPadOS 26 以降が必要で、タイプライターモードは Markdown の文章では働きません。無料体験のあと文章の編集を続けるには、メンバーシップが必要です。
- リッチテキストには対応しておらず、太字や画像は Markdown で扱います。

詳しくは[ユーザーマニュアル](/en/manual/)（英語）をご覧ください。

## よくある質問 {#faq}

### 集中して書ける執筆アプリとは何ですか？

書いているあいだ本文以外のものが邪魔をしないように作られた執筆アプリです。画面を本文だけにでき、タイムラインや広告がなく、保存や同期を意識せずに済みます。

### スマホで小説を書くなら、どの執筆アプリがおすすめですか？

誰にとっても一番というアプリはありません。いくつか試し、画面を本文だけにできるか、自動保存と履歴があるか、縦書きが必要なら対応しているかを確かめて選ぶのが確実です。純純執筆も選択肢のひとつで、Android 版は主要な機能を無料・広告なしで使えます。

### iPad で使える執筆アプリはありますか？

App Store に多くあります。iPad では、横向きでの行の長さと外付けキーボードへの対応も確かめましょう。純純執筆 iOS 版も iPhone と iPad の両方に対応しています（iOS 26・iPadOS 26 以降）。

### 集中モードやサイレントモードだけでは足りませんか？

iPhone の集中モードや Android のサイレントモードはほかのアプリの通知を止めるもので、オンにしておく価値があります。ただ、執筆アプリのツールバーや書式ボタン、保存を気にする必要があるかどうかは変わりません。両方を組み合わせましょう。

### 買い切りの執筆アプリはありますか？

料金の形はアプリごとに違うので、ストアで確かめてください。純純執筆 iOS 版は 7 日間の無料体験のあと、月額プラン、年額プラン、または買い切りの永久メンバーシップを選べます。パソコン版は現在は無料です。
